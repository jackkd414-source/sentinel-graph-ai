# Internal process records

These documents record how the project was reviewed, remediated and released.
They are working history: useful for tracing why a decision was made, not
required reading to install or use the product.

| Document | What it records |
|---|---|
| [`FINAL_RELEASE_REPORT.md`](FINAL_RELEASE_REPORT.md) | The state of the repository at release: what shipped, what was verified. |
| [`FINAL_REMEDIATION_REPORT.md`](FINAL_REMEDIATION_REPORT.md) | Every finding raised in review, and how each one was closed. |
| [`REMEDIATION_REPORT.md`](REMEDIATION_REPORT.md) | The original remediation plan and its findings. |
| [`REMEDIATION_PROGRESS.md`](REMEDIATION_PROGRESS.md) | Progress log kept while the remediation was in flight. |

They were moved out of the repository root so the root shows only what a reader
needs: the README, the licence, the build files and the source directories.

Mentions of sibling documents inside these files are plain text, not links, so
they still read correctly from this folder.
